# StudySnap Pro — Learning UI Renovation Pass 3

## Baby / Early Learning
- Reduced visual noise and oversized gradients.
- Replaced large six-card vertical feel with compact responsive activity cards.
- Reduced decorative motion intensity.
- Preserved child-friendly interactions, voice feedback, music, and video learning.

## YouTube Learning
- Reduced section padding and card density.
- Converted long horizontal category strip into a responsive category grid.
- Kept safe-mode video embedding, loading/error/empty states, and lazy thumbnails.
- Video cards now scale across phone, tablet, and desktop without creating excessive vertical space.

## Research
- Research result view uses a tighter content width and compact source grid.
- Source cards remain individually accessible while avoiding one huge long list.
- Research Hub continues to separate live web research from community projects.

## Intent
The UI should feel progressively disclosed: show the primary task first, then reveal advanced controls when needed. The user should not need to scroll through the entire feature set to understand what to do.
