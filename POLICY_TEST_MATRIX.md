# Policy test matrix

| Profile | Expected access |
|---|---|
| baby + student | early learning, search, safe voice tutor, videos |
| kid + student | core learning, AI tutor, voice, revision, homework, no public social/commerce |
| teen + student + no institution | study/revision/research, no public social, no live classroom |
| teen + student + institution | same + supervised live classroom |
| adult + student | adult learning, research, collaboration, community/marketplace as enabled |
| adult + teacher | teacher analytics, classroom, institution and research tools |
| adult + researcher | research and advanced analysis tools |
| adult + admin | admin and institution controls |
| any minor + requested privileged role | remains student until trusted admin provisioning |
