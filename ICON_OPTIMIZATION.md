# StudySnap Professional Icon Upgrade

The supplied StudySnap Pro artwork is now the canonical app brand icon.

Changes:
- High-resolution 2048px master-derived PNG assets.
- Crisp 16/32/48px favicons.
- 180px Apple touch icon.
- 192/512px PWA icons.
- Separate maskable 192/512px icons for Android/adaptive icon surfaces.
- Manifest now declares `any` and `maskable` icons separately.
- Shortcut icons use PNG assets instead of the complex SVG wrapper.
- Browser theme color updated to StudySnap blue.
- Service-worker cache bumped to v6 so installed users receive the new icon assets.
