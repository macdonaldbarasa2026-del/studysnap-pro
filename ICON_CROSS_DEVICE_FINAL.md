# StudySnap Pro — Cross-device icon finalization

- Canonical artwork: `public/pwa-icon-1024.png`
- Standard PWA icons: 192, 512, 1024 PNG
- Maskable PWA icons: 192, 512, 1024 PNG with the artwork kept inside the adaptive safe area
- Apple Home Screen: 180x180 PNG
- Browser favicons: 16, 32, 48 PNG + multi-resolution `favicon.ico`
- Tiny browser icons use a compact camera/book mark so the identity remains recognizable at 16–48 px.
- Manifest orientation is `any` for phones, tablets, foldables, desktops and landscape displays.
- Manifest includes both `any` and `maskable` purposes.
- Windows/desktop tile metadata is included.
